## 📂 Mes projets

### ⚡ EV Market Analytics — Data Warehouse & BI Véhicules Électriques
**Technologies :** Python • Snowflake • dbt • Apache Airflow • Power BI • Docker

- Pipeline ELT de bout en bout en **architecture Médaillon** (Bronze, Silver, Gold) sur plus de 2 000 enregistrements de véhicules électriques.
- Transformations dbt : doublons, valeurs manquantes, outliers, feature engineering, tests de qualité.
- Modèle en étoile (`fact_vehicle`, `dim_brand`, `dim_vehicle`) et orchestration avec Airflow sous Docker.
- Dashboard Power BI de 4 pages : accueil, vue globale du marché, analyse des prix, performance des véhicules.
